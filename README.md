# English to Tamil Translator 🌐

A simple, elegant web-based translator that converts English text to Tamil. Perfect for learning basic Tamil words and phrases!

## Features ✨

- **Clean Interface**: Modern, responsive design that works on all devices
- **Instant Translation**: Quick translation with a single click
- **Rich Dictionary**: Includes common words, phrases, numbers, colors, and more
- **Smart Matching**: Handles both exact phrases and word-by-word translation
- **Keyboard Support**: Press Enter to translate, Ctrl+L to clear

## How to Use 🚀

1. Open `index.html` in your web browser
2. Type English text in the input area
3. Click "Translate" or press Enter
4. View the Tamil translation in the output area

## Dictionary Coverage 📚

The translator includes:
- Common greetings and phrases
- Family members
- Numbers (1-10)
- Colors
- Food items
- Basic verbs
- Time-related words
- Places
- Everyday expressions

## Examples 💬

- "hello" → "வணக்கம்"
- "thank you" → "நன்றி"
- "good morning" → "காலை வணக்கம்"
- "how are you" → "எப்படி இருக்கிறீர்கள்"
- "i love you" → "நான் உன்னை காதலிக்கிறேன்"

## Technical Details 🛠️
