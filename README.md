# Fresh

A modern web application built with Node.js.

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/volleyboyk17/Fresh.git
cd Fresh

# Install dependencies
npm install

# Start development server
npm run dev
```

## 📋 Prerequisites

- Node.js (v18 or higher)
- npm or yarn
- Git
